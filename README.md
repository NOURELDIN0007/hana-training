# Hana's assessment studio

Live site: https://noureldin0007.github.io/hana-training/

Open index.html to preview the site. Keep index.html, studio.js, studio.css and question-bank.js together. The original lessons and briefing are in index.html. Push a commit to main to publish at the same address. Browser storage preserves practice progress, response drafts, timed history and the active full mock. Its deadline continues during a refresh.
